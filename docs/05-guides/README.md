# AICF Guides (Planned)

## Purpose

The **Guides** section provides user-facing documentation, tutorials, and practical walk-throughs for engineers and teams adopting AICF.

### Planned Guides
1. **Getting Started:** Quickstart tutorial on using AICF in an existing or new project.
2. **Creating an AICF Project:** Step-by-step walkthrough of initializing `.aicf/` with canonical artifacts.
3. **Adopting AICF in Brownfield Codebases:** Practical strategies for introducing AICF incrementally to legacy or production repositories without disruptions.
4. **Contribution Guide:** How to author new schemas, contribute adapters, and participate in framework governance (cross-linked with [CONTRIBUTING.md](../../CONTRIBUTING.md)).
5. **Migration Guides:** How to migrate project-level `.aicf/` directories across AICF framework releases.
