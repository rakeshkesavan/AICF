# AICF Reference Examples (Planned)

## Overview

This directory provides working reference implementations demonstrating how to configure and use AICF in various application architectures and technology stacks.

## Planned Examples

- **`minimal/`**: A bare-minimum example demonstrating the five foundational artifacts in a lightweight script repository.
- **`angular-java/`**: Enterprise web application featuring an Angular frontend and a Spring Boot / Java backend, demonstrating cross-tier context and API contract rules.
- **`react-node/`**: Modern full-stack JavaScript/TypeScript application with Next.js or React + Node.js.
- **`monorepo/`**: Multi-package repository architecture demonstrating shared rules, domain-specific requirements, and scoped task execution.
