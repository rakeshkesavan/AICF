# AICF Tooling (Planned)

## Overview

The `tooling/` directory contains developer tools, automation scripts, and command-line interfaces for creating and maintaining AICF-compliant codebases.

## Structure

- **`cli/`**: The AICF Command-Line Interface (`aicf`). Planned capabilities include:
  - `aicf init`: Project bootstrap and template generation.
  - `aicf detect`: Framework and stack discovery.
  - `aicf validate`: Artifact syntax, schema, and reference checking.
  - `aicf status`: Visual summary of project health, active tasks, and state.
  - `aicf adapter`: Generator for editor/agent adapters (Cursor, Claude, Gemini, Antigravity).

---

> [!NOTE]
> **Status: Planned**  
> CLI implementation will commence after the Bootstrap & Discovery specification (AICF-001) is complete.
