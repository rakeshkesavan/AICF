# AICF Project

This project uses AICF (AI Coding Framework).

AICF Core defines the universal engineering methodology.

This `.aicf/` directory contains project-specific engineering context,
state, requirements, decisions, tasks, and validation records.

Tool-specific instructions are maintained through the appropriate
AICF tool adapter.

The repository implementation remains the source of truth for actual
software behaviour.

## AICF Version

0.1

## Directory Structure

- `rules.md` — project-specific engineering and AI operating rules
- `project.md` — stable project context
- `state.md` — current recoverable project state
- `environment.md` — environment definitions and differences
- `decisions/` — material engineering/product decisions
- `domains/` — domain knowledge
- `features/` — feature context
- `requirements/` — requirements and acceptance criteria
- `tasks/` — bounded engineering tasks
- `validation/` — validation evidence
