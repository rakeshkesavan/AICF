# AICF Starter Status

This starter repository contains the initial project-layer implementation
of AICF v0.1.

## Included

- Core project README
- Project rules
- Project context
- Recoverable project state
- Environment model
- Templates for decisions, domains, features, requirements, tasks, and validation

## Not Included

- Tool-specific adapters
- AICF Core specification
- Automatic context retrieval
- CLI/runtime automation
- Project-specific content

Those belong to later AICF phases.
